  nào chạy sót.

  File mới và sửa:
  - Server: server/package.json, server.js, lib/validateMessage.js,
    lib/store.js, lib/validateMessage.test.js.
  - Gốc repo: .env.example (PORT, CLIENT_ORIGIN, VITE_API_URL).
  - Client: hooks/useForumMessages.js, pages/Forum.jsx, pages/Forum.module.css.
  - Sửa App.jsx (route forum/:channelId) và Layout.jsx (link Forum).

  Điều bạn cần làm trước khi thử trên trình duyệt: tạo 2 file .env (đã bị git bỏ
  qua) từ .env.example:
  - server/.env: PORT=3000 và CLIENT_ORIGIN=http://localhost:5173.
  - client/.env: VITE_API_URL=http://localhost:3000.

  Rồi chạy npm run dev trong cả server/ và client/, mở /forum/nasa.

  Điều tôi chưa chắc: hook gọi setState ở đầu effect để chuyển sang LOADING mỗi
  khi đổi kênh. Đây là việc bắt đầu fetch nên hợp lệ, nhưng nếu bạn thấy cảnh
  báo trong React DevTools thì báo tôi.
